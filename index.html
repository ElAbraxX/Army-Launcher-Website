KRYON SERVICE · PARA JUGADORES

Tu modpack al día,
con tu launcher de siempre.

Kryon Service Updater sincroniza los archivos de un modpack administrado con una instancia de Minecraft que ya tengas creada. Puedes seleccionar la carpeta de una instancia de otros launchers y seguir abriendo el juego como acostumbras.

  • Compara los archivos antes de aplicar cambios.
  • Conserva los archivos que hayas modificado por tu cuenta.
  • No instala cargadores ni inicia Minecraft.

LAUNCHER O ACTUALIZADOR

Los dos pueden sincronizar archivos de un modpack, pero se conectan de forma distinta y tienen funciones diferentes.

FunciónKryonCraft LauncherKryon Service Updater
Uso principalAdministra instancias y versiones, elige cargadores y abre Minecraft.Actualiza los archivos de un modpack dentro de una instancia ya creada.
Conexión del packSincroniza el manifiesto configurado en el launcher.Conecta el código KRYON que comparte el administrador del servidor.
Carpeta que actualizaLa instancia que administra el launcher.La carpeta elegida por el jugador, incluso si la creó otro launcher.
Después de sincronizarPuede iniciar Minecraft desde el propio launcher.No inicia Minecraft: abre la instancia con tu launcher habitual.

Cuenta y permisos

Para iniciar Minecraft Java se requiere una cuenta Microsoft con licencia. La distribución de mods depende de los permisos de sus autores y de las condiciones de cada plataforma. KryonCraft no aloja ni vende mods de terceros.
