HECHO PARA JUGAR

Todo claro antes
de darle a Jugar.

Elige una instalación local o importa un pack. Army separa esas opciones para que no tengas que configurar GitHub si solo quieres iniciar Minecraft.

A

INSTANCIAS LOCALES

Elige versión y cargador.

Prepara perfiles de Minecraft Java con Vanilla, Fabric, Forge, NeoForge, Quilt, Legacy Fabric, Ornithe o Babric. LiteLoader aparece en el catálogo; su instalación sigue pendiente.

VanillaForgeFabricNeoForgeQuilt
↻

MODPACKS

Importa a tu ritmo.

Abre paquetes .mrpack de Modrinth y ZIP exportados de CurseForge, o agrega archivos .jar manualmente. La descarga de mods de CurseForge depende de la API oficial y sus permisos.

◉

TU EQUIPO

Ajusta la experiencia.

Personaliza colores y tamaño del launcher, configura Java y memoria, y consulta registros desde la aplicación de escritorio.

ACTUALIZACIONES DEL MODPACK

El repositorio es opcional para jugar.

Si un administrador publica un manifiesto en GitHub, Army puede comprobar los cambios y sincronizar los archivos de esa instancia. Los jugadores no necesitan configurar una cuenta de GitHub.

Cuenta y permisos

Para iniciar Minecraft Java se requiere una cuenta Microsoft con licencia. La distribución de mods depende de los permisos de sus autores y de las condiciones de cada plataforma. Army no aloja ni vende mods de terceros.
